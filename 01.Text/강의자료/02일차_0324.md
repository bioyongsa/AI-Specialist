
# Decoder의 각 구성 요소 설명

* **Normalization** -> Masked Multi-head Attention -> **Dropout** _(순환)_
* 위의 모델 **(+)** 아래의 모델 => 여기에서 (+) 부분이 "잔차 연결"
* **Normalization** -> **FFN** -> **Dropout** _(순환)_

## Dropout
* 모델이 큰데, 데이터가 충분하지 않은 경우 발생

## Normalization
* 평균이 0이고, 표준편차가 1이 되도록 반환
* 과도한 정규화는 학습효과가 사라짐
* {데이터 값 - 평균}을 분산으로 나눠줌
* LLM: Layer Normalization, Vision: Batch Normalization을 주로 사용
* RMS Normalization: 평균을 0으로 맞추는 것보다 데이터의 크기 (scale)를 일정하게 유지...

## FFN (Feed Forward Network)
* 수집된 정보 해석, 지식 저장
* Vector가 직교함 => 내적이 0임
* 직교하지 않고 89도로 하면, hallucination이 발생하게 됨 (p.125)
* 선형층(확장) -> **활성화 함수** -> 선형층(축소) (p.129)
* 확장된 layer에서는 해당 layer에서 특정 뉴런이 삭제(비활성)되더라도 output에서는 input과 같은 크기로 유지될 수 있으므로 확장층을 사용

### 활성화 함수
* Sigmoid: 참/거짓만 판단. 복잡한 패턴 학습 가능, layer가 많아질 수록 vanishing gradient problem..
* ReLU: sigmoid의 vanishing 이슈를 해결하기 위해 layer를 깊게 쌓음, ReLU(x) = max(0, x), but 0 이하에서는 0으로 만들어줌 (비활성 뉴런이 많아짐), 0 에서는 미분 불가
* GELU: ReLU의 0이하 부분을 보완하기 위함. ReLU와 유사하지만, 0 이하의 처리가 다름. 안정화된 처리 가능

## Dataset
### Training
* Training Data
* Validatuin Data: overfitting 방지 목적

1. 순전파 입력 (에측값 계산)
2. 오차 계산 (Loss): 예측값 vs 정답, Loss 계산 - 비용 함수 (예, MSE, Cross Entropy (정답 token의 확률 합이 모두 1이면 됨))

* 용어 정리
  batch size: step 1번에 사용하는 data의 사이즈
  step: 파라미터를 1회 업데이트 하는 것
  epoch: 전체 data를 1회 학습하는 것

* Inference vs training (p.148)
  inference: 1 token씩 예측하며 auto-regressive로...
  training: target 전체에 대해서 loss 계산

## Fine-Tuning
* 분류를 위해 마지막 layer 수정 (cross-entropy)
### LoRA (PEFT의 일종)
* LLM 학습의 문제는 많은 메모리 요구..
* adapter fine-tuning의 일종으로 모델 학습에 일부의 파라미터들만 사용 (cf: full fine-tuning (Optimizer Adam..)
* LoRA 의 원리 (p.159): A * B의 구조에서 작은 rank의 값을 사용함으로써 A * B는 high precision weighting 가능
* LoRA의 초기화는 A는 random, B는 0으로... 만약 A도 B도 모두 0이면, 기울기 계산을 하지 않아서 weight가 update되지 않음.
* QLoRA: 양자화된 LoRA, 4-bit QLoRA이면, {-1, 1} 구간에서 정규화된 값을 2^4개의 구간으로 쪼갬 (균일하지 않은 간격).
  원본은 freezing, adapter 부분만 training에 참여함.

### 지시 미세 튜닝 (Supervised Fine-Tuning)
* input data: 맨 마지막의 바로 앞까지...
* target data: 맨 처음부터 맨 마지막의 바로 앞까지...
* zero padding: 50256
* target에서 prompt에 해당하는 부분: 맨 처음의 50256만 남겨놓고, 그 다음의 50256은 -100으로 padding함

### RLHF

### GQA
* K, V를 그룹화해서 caching해서 사용

### MLA
* Latent Space를 생성해서 caching을 하고 K, V의 값을 구함
* GQA에 비해서 memory도 적게 사용하고, 성능은 더 뛰어남 (DeepSeek)

### MOE (Mixture of Experts)
* "Qwen-30B-A3B" 같은 모델.. 전체 파라미터 갯수: 30 billion, 한 번의 inference에 사용되는 activated 파라미터 갯수: 3 billion
* Decoder에서의 FFN을 "rounter + 다수개의 FFN"으로 나눠서 구현한 모델 (즉, FFN을 다수개의 FFN으로 나눠서 router가 분기해줌)
* 대부분의 거대 LLM 모델은 FFN -> MOE 형태로 사용하고 있음

### Sliding Window Attention
* 기존의 casual self-attention mask는 대각선의 윗쪽만 masking, but sliding window attention은 일정 길이 만큼의 앞만 바라봄

### 넓이 vs 깊이 ?
* 넓이를 키움: Multi-Header Attention의 header를 늘림, 속도가 빠름 (e.g.: Mistral)
* 깊이를 키움: Transpormer의 layer 갯수를 늘림, 모델의 추론 성능이 좋아짐 (e.g.: Gemma)
