## 1. Linear Quantization 이론

### 핵심 수식

Linear Quantization(선형 양자화)의 핵심은 **부동소수점(FP32)** 실수 $r$과 **정수** $q$ 사이의 선형 매핑입니다.

$$r = S \cdot (q - Z)$$

| 기호 | 타입 | 의미 |
|------|------|------|
| $r$ | `float` | 원본 부동소수점 값 |
| $S$ | `float` | **Scale** (스케일 팩터) |
| $q$ | `int` (n-bit) | 양자화된 정수 값 |
| $Z$ | `int` | **Zero Point** (영점) |

역방향(FP32 → 정수)으로 변환하면:

$$q = \text{round}\!\left(\frac{r}{S}\right) + Z$$

### 개념 도식

```
FP32 범위:  [fp_min ─────────────────────── fp_max]
                  ↕  scale S, zero point Z
INT 범위:   [q_min ─────────────────────── q_max]
            (예: 8-bit → [-128, 127])
```

---

## 2. n-bit 정수 범위 계산 — `get_quantized_range`

```python
def get_quantized_range(bitwidth):
    quantized_max = (1 << (bitwidth - 1)) - 1   # 2^(n-1) - 1
    quantized_min = -(1 << (bitwidth - 1))        # -2^(n-1)
    return quantized_min, quantized_max
```

### 설명

n-bit **2의 보수(two's complement)** 표현의 범위를 계산합니다.

```
비트폭 | quantized_min | quantized_max
-------+---------------+---------------
 2-bit |      -2       |       1
 4-bit |      -8       |       7
 8-bit |    -128       |     127
```

- `1 << (bitwidth - 1)` = $2^{n-1}$
- signed 정수이므로 양수 범위는 $2^{n-1}-1$, 음수 범위는 $-2^{n-1}$까지입니다.

## 3. 핵심 양자화 함수 — `linear_quantize`

```python
def linear_quantize(fp_tensor, bitwidth, scale, zero_point, dtype=torch.int8):
    # Step 1: fp_tensor를 scale로 나누기
    scaled_tensor = fp_tensor / scale

    # Step 2: 부동소수점 → 정수로 반올림
    rounded_tensor = torch.round(scaled_tensor)
    rounded_tensor = rounded_tensor.to(dtype)

    # Step 3: zero_point만큼 shift (영점 이동)
    shifted_tensor = rounded_tensor + zero_point

    # Step 4: n-bit 범위로 clamp (절사)
    quantized_min, quantized_max = get_quantized_range(bitwidth)
    quantized_tensor = shifted_tensor.clamp_(quantized_min, quantized_max)

    return quantized_tensor
```

### 단계별 도식

```
원본 FP32 텐서 (r)
        │
        ▼
  ÷ scale (S)          ← r / S
        │
        ▼
  round() 반올림        ← 부동소수점 정수 값
        │
        ▼
  .to(int8) 타입 변환
        │
        ▼
  + zero_point (Z)     ← 영점 이동
        │
        ▼
  clamp(q_min, q_max)  ← n-bit 범위 벗어난 값 절사
        │
        ▼
  양자화된 정수 텐서 (q)
```

### 핵심 포인트

- **Step 2 → int8 변환 순서 주의**: `round()` 후 `to(int8)` 해야 합니다. 반올림 전에 변환하면 반올림 오차가 남습니다.
- **Clamp**: 반올림 후 값이 n-bit 범위를 벗어날 수 있으므로 절사 처리합니다.

## 4. Scale과 Zero Point 계산 — `get_quantization_scale_and_zero_point`

```python
def get_quantization_scale_and_zero_point(fp_tensor, bitwidth):
    quantized_min, quantized_max = get_quantized_range(bitwidth)
    fp_max = fp_tensor.max().item()
    fp_min = fp_tensor.min().item()

    # Scale 계산: FP 범위를 정수 범위로 선형 매핑
    scale = (fp_max - fp_min) / (quantized_max - quantized_min)

    # Zero Point 계산: q_min - fp_min/S
    zero_point = round(quantized_min - fp_min / scale)

    # Zero Point를 [q_min, q_max] 범위로 clip
    if zero_point < quantized_min:
        zero_point = quantized_min
    elif zero_point > quantized_max:
        zero_point = quantized_max
    else:
        zero_point = round(zero_point)

    return scale, int(zero_point)
```

### Scale 유도 과정

두 수식을 이용합니다:

$$r_{\max} = S \cdot (q_{\max} - Z), \quad r_{\min} = S \cdot (q_{\min} - Z)$$

두 식을 빼면:

$$S = \frac{r_{\max} - r_{\min}}{q_{\max} - q_{\min}}$$

### Zero Point 유도 과정

$r_{\min} = S \cdot (q_{\min} - Z)$ 에서:

$$Z = q_{\min} - \frac{r_{\min}}{S}$$

### 도식 — FP32 → INT 범위 매핑

```
FP32:  fp_min ←─────────────────────────→ fp_max
              ←── fp_max - fp_min ──────→

INT:   q_min  ←─────────────────────────→ q_max
              ←── q_max - q_min ────────→

Scale = (fp_max - fp_min) / (q_max - q_min)

FP32의 0.0이 INT에서의 Z(Zero Point)에 해당
```

## 5. Feature 양자화 통합 — `linear_quantize_feature`

```python
def linear_quantize_feature(fp_tensor, bitwidth):
    scale, zero_point = get_quantization_scale_and_zero_point(fp_tensor, bitwidth)
    quantized_tensor = linear_quantize(fp_tensor, bitwidth, scale, zero_point)
    return quantized_tensor, scale, zero_point
```

### 역할

`get_quantization_scale_and_zero_point()`와 `linear_quantize()`를 하나로 묶은 **편의 래퍼(wrapper)** 함수입니다.

**활성화(activation)** 텐서(feature map)를 양자화할 때 사용합니다.

## 6. 가중치 양자화 특수 케이스

### 왜 가중치는 다르게 처리하나?

가중치의 분포는 **0을 중심으로 대칭**입니다. 이 특성을 이용하면:
- Zero Point $Z = 0$ 으로 설정
- 수식 단순화: $r_{\text{weight}} = S \cdot q_{\text{weight}}$

### 6-1. Scale 계산 — `get_quantization_scale_for_weight`

```python
def get_quantization_scale_for_weight(weight, bitwidth):
    # 가중치 분포가 대칭 → Z = 0
    # fp_max = max(|weight|) (절대값 최대)
    fp_max = max(weight.abs().max().item(), 5e-7)  # 수치 안정성을 위한 최솟값
    _, quantized_max = get_quantized_range(bitwidth)

    return fp_max / quantized_max
```

#### 수식

$$S = \frac{r_{\max}}{q_{\max}}$$

- $r_{\max}$: 가중치 텐서의 **절대값 최대값**
- 최솟값 `5e-7`은 분모가 0이 되는 수치 불안정 방지

---

### 6-2. Per-Tensor 가중치 양자화 — `linear_quantize_weight_per_tensor`

```python
def linear_quantize_weight_per_tensor(tensor, bitwidth):
    # 텐서 전체에 단 하나의 scale 계산
    scale_value = get_quantization_scale_for_weight(tensor, bitwidth)
    scale = torch.tensor([scale_value], device=tensor.device)

    # scale shape을 출력 채널 수에 맞게 확장
    scale_shape = [1] * tensor.dim()
    scale_shape[0] = tensor.shape[0]
    scale_per_channel = scale.expand(scale_shape)

    quantized_tensor = linear_quantize(tensor, bitwidth, scale_per_channel, zero_point=0)
    return quantized_tensor, scale_per_channel, 0
```

#### 도식 — Per-Tensor vs Per-Channel

```
가중치 텐서 shape: [out_ch, in_ch, kH, kW]

Per-Tensor:
  ┌──────────────────────────────────────┐
  │        전체에 단 1개의 scale S       │
  └──────────────────────────────────────┘

Per-Channel:
  ┌──────────┬──────────┬──────────┬─────┐
  │  S[ch0]  │  S[ch1]  │  S[ch2]  │ ... │
  │ (ch0용)  │ (ch1용)  │ (ch2용)  │     │
  └──────────┴──────────┴──────────┴─────┘
  출력 채널별로 독립적인 scale
```

**Per-Tensor 특성:**
- 구현 간단, 연산량 적음
- 큰 모델에서 잘 동작
- 채널별 값 분포 편차가 클 때 정확도 손실 가능

---

### 6-3. Per-Channel 가중치 양자화 — `linear_quantize_weight_per_channel`

```python
def linear_quantize_weight_per_channel(tensor, bitwidth):
    dim_output_channels = 0
    num_output_channels = tensor.shape[dim_output_channels]

    # 각 출력 채널별로 scale을 개별 계산
    scale = torch.zeros(num_output_channels, device=tensor.device)
    for oc in range(num_output_channels):
        _subtensor = tensor.select(dim_output_channels, oc)
        _scale = get_quantization_scale_for_weight(_subtensor, bitwidth)
        scale[oc] = _scale

    # scale shape: [out_ch, 1, 1, 1] (브로드캐스팅용)
    scale_shape = [1] * tensor.dim()
    scale_shape[dim_output_channels] = -1
    scale = scale.view(scale_shape)

    quantized_tensor = linear_quantize(tensor, bitwidth, scale, zero_point=0)
    return quantized_tensor, scale, 0
```

**Per-Channel 특성:**
- 채널별 독립적인 scale → 정확도 우수
- 최근 연구에서 Per-Tensor 대비 성능 향상 확인

## 7. Bias 양자화 — `linear_quantize_bias_per_output_channel`

```python
def linear_quantize_bias_per_output_channel(bias, weight_scale, input_scale):
    # bias_scale = input_scale × weight_scale
    bias_scale = input_scale * weight_scale

    # bias는 32-bit 정수로 양자화, zero_point = 0
    quantized_bias = linear_quantize(bias, 32, bias_scale, zero_point=0, dtype=torch.int32)
    return quantized_bias, bias_scale, 0
```

### 왜 Bias Scale = Input Scale × Weight Scale인가?

Convolution 연산을 수식으로 전개하면:

$$r_{\text{output}} = \text{CONV}[r_{\text{input}}, r_{\text{weight}}] + r_{\text{bias}}$$

여기서 $r = S \cdot (q - Z)$를 대입하면, bias 항의 스케일이 자연스럽게:

$$S_{\text{bias}} = S_{\text{input}} \cdot S_{\text{weight}}$$

로 결정됩니다. 또한 **수치 정밀도 유지**를 위해 bias는 **32-bit 정수**로 양자화합니다.

## 8. Integer-only Inference (정수 기반 추론)

### 핵심 아이디어

양자화 후 추론은 **정수 연산만으로** 수행합니다. Float 연산을 최소화해 속도와 에너지 효율을 높입니다.

### 8-1. FC Bias Shift — `shift_quantized_linear_bias`

```python
def shift_quantized_linear_bias(quantized_bias, quantized_weight, input_zero_point):
    # Q_bias = q_bias - Linear[Z_input, q_weight]
    return quantized_bias - quantized_weight.sum(1).to(torch.int32) * input_zero_point
```

#### 수식 유도

입력에 Zero Point $Z_{\text{input}}$가 있으면 Linear 연산에서 다음 항이 발생합니다:

$$\text{Linear}[q_{\text{input}} - Z_{\text{input}},\; q_{\text{weight}}]
= \text{Linear}[q_{\text{input}},\; q_{\text{weight}}] - Z_{\text{input}} \cdot \sum_j q_{\text{weight},j}$$

이 보정값을 bias에 미리 흡수합니다:

$$Q_{\text{bias}} = q_{\text{bias}} - Z_{\text{input}} \cdot \underbrace{\sum_j q_{\text{weight},j}}_{\texttt{quantized\_weight.sum(1)}}$$

추론 시 복잡한 Zero Point 보정 없이 정수 연산만으로 처리 가능해집니다.

---

### 8-2. 양자화된 FC 레이어 — `quantized_linear`

```python
def quantized_linear(input, weight, bias, feature_bitwidth, weight_bitwidth,
                     input_zero_point, output_zero_point,
                     input_scale, weight_scale, output_scale):
    # Step 1: 정수 기반 FC 연산 (8-bit 곱, 32-bit 누산)
    if 'cpu' in input.device.type:
        output = torch.nn.functional.linear(input.to(torch.int32), weight.to(torch.int32), bias)
    else:
        output = torch.nn.functional.linear(input.float(), weight.float(), bias.float())

    # weight_scale shape 조정: [oc, 1, 1, 1] → [1, oc]
    weight_scale = weight_scale.flatten().view(1, -1)
    output = output.float()

    # Step 2: 출력 텐서 scale 변환
    output = output * (input_scale * weight_scale / output_scale)

    # Step 3: output_zero_point 이동
    output = output + output_zero_point

    # 최종 clamp + int8 변환
    output = output.round().clamp(*get_quantized_range(feature_bitwidth)).to(torch.int8)
    return output
```

#### 최종 수식

$$q_{\text{output}} = \text{round}\!\left[(\text{Linear}[q_{\text{input}}, q_{\text{weight}}] + Q_{\text{bias}}) \cdot \frac{S_{\text{input}} \cdot S_{\text{weight}}}{S_{\text{output}}} + Z_{\text{output}}\right]$$

#### 도식

```
q_input (int8)  q_weight (int8)
      │                │
      └───── Linear ───┘
                │
         + Q_bias (int32)
                │
        × (S_input × S_weight / S_output)   ← FP32로 변환 후 scaling
                │
        + Z_output
                │
           round()
                │
          clamp(q_min, q_max)
                │
        q_output (int8)
```

---

### 8-3. Conv Bias Shift — `shift_quantized_conv2d_bias`

```python
def shift_quantized_conv2d_bias(quantized_bias, quantized_weight, input_zero_point):
    # Q_bias = q_bias - CONV[Z_input, q_weight]
    # 4D 가중치 (out_ch, in_ch, kH, kW) → 채널별 합산
    return quantized_bias - quantized_weight.sum((1,2,3)).to(torch.int32) * input_zero_point
```

FC와 동일한 원리이나, Conv2d의 가중치는 4D 텐서이므로 `(1,2,3)` 축 전체를 합산합니다.

---

### 8-4. 양자화된 Conv2d 레이어 — `quantized_conv2d`

```python
def quantized_conv2d(input, weight, bias, feature_bitwidth, weight_bitwidth,
                     input_zero_point, output_zero_point,
                     input_scale, weight_scale, output_scale,
                     stride, padding, dilation, groups):

    # Step 1: zero_point로 패딩 후 정수 기반 Conv2d
    input = torch.nn.functional.pad(input, padding, 'constant', input_zero_point)
    if 'cpu' in input.device.type:
        output = torch.nn.functional.conv2d(input.to(torch.int32), weight.to(torch.int32),
                                            None, stride, 0, dilation, groups)
    else:
        output = torch.nn.functional.conv2d(input.float(), weight.float(),
                                            None, stride, 0, dilation, groups)
        output = output.round().to(torch.int32)

    if bias is not None:
        output = output + bias.view(1, -1, 1, 1)

    # weight_scale shape 조정: [oc, 1, 1, 1]
    weight_scale = weight_scale.flatten().view(1, -1, 1, 1)
    output = output.float()

    # Step 2: scale 변환
    output = output * (input_scale * weight_scale / output_scale)

    # Step 3: output_zero_point 이동
    output = output + output_zero_point

    output = output.round().clamp(*get_quantized_range(feature_bitwidth)).to(torch.int8)
    return output
```

#### FC와의 주요 차이점

| 항목 | FC (`quantized_linear`) | Conv2d (`quantized_conv2d`) |
|------|------------------------|---------------------------|
| 패딩 방식 | 별도 처리 없음 | `input_zero_point` 값으로 패딩 |
| weight_scale 뷰 | `[1, oc]` | `[1, oc, 1, 1]` |
| weight 합산 | `.sum(1)` | `.sum((1,2,3))` |

**패딩 주의**: 일반적인 패딩(0)이 아닌, **`input_zero_point`로 패딩**합니다. 양자화 관점에서 "0"의 의미가 zero_point이기 때문입니다.

## 9. 전체 모델 양자화 과정

### 전체 흐름

```
FP32 모델
    │
    ▼
[1] fuse_conv_bn()          ← Conv + BN을 하나의 Conv로 합침
    │
    ▼
[2] add_range_recoder_hook() ← 샘플 데이터로 activation 범위 기록
    │  (훈련 데이터 일부 forward)
    ▼
[3] QuantizedConv2d / QuantizedLinear 변환
    │  (scale, zero_point, 양자화된 weight/bias 계산)
    ▼
Quantized 모델 (INT8)
```

---

### 9-1. Conv-BN 융합 — `fuse_conv_bn`

```python
def fuse_conv_bn(conv, bn):
    # Conv 뒤에 BN이 붙을 때 BN을 Conv로 흡수
    factor = bn.weight.data / torch.sqrt(bn.running_var.data + bn.eps)
    conv.weight.data = conv.weight.data * factor.reshape(-1, 1, 1, 1)
    conv.bias = nn.Parameter(- bn.running_mean.data * factor + bn.bias.data)
    return conv
```

#### 수학적 원리

BatchNorm은 다음 연산입니다:

$$\text{BN}(x) = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

Conv 출력 $x = W * \text{input} + b$ 를 BN에 통과시키면:

$$\text{BN}(\text{Conv}(x)) = \frac{\gamma}{\sqrt{\sigma^2 + \epsilon}} \cdot (W * \text{input}) + \left(\frac{\gamma}{\sqrt{\sigma^2 + \epsilon}} \cdot b - \frac{\gamma \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta\right)$$

즉, BN을 **새로운 Conv의 weight/bias로 흡수**할 수 있습니다:

$$W' = W \cdot \frac{\gamma}{\sqrt{\sigma^2 + \epsilon}}, \quad b' = -\mu \cdot \frac{\gamma}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

#### 도식

```
[Before] Conv → BN → ReLU  (3개 연산)
                ↓ fuse
[After]  Conv'  → ReLU     (2개 연산, BN 파라미터 흡수)
```

BN 융합은 **동등 변환(equivalent transformation)** 이므로 정확도 변화 없음.

---

### 9-2. Activation Range 기록 — `add_range_recoder_hook`

```python
def add_range_recoder_hook(model):
    import functools
    def _record_range(self, x, y, module_name):
        x = x[0]
        input_activation[module_name] = x.detach()
        output_activation[module_name] = y.detach()

    all_hooks = []
    for name, m in model.named_modules():
        if isinstance(m, (nn.Conv2d, nn.Linear, nn.ReLU)):
            all_hooks.append(m.register_forward_hook(
                functools.partial(_record_range, module_name=name)))
    return all_hooks
```

#### 동작 원리

PyTorch의 **forward hook**을 활용합니다. 각 레이어의 순전파 시 입·출력 텐서를 딕셔너리에 저장합니다.

```
샘플 데이터 → Conv2d_0 → [입출력 저장] → ReLU_0 → [입출력 저장] → ...
```

저장된 activation 범위는 이후 scale/zero_point 계산에 사용됩니다.

---

### 9-3. 양자화 레이어 클래스 — `QuantizedConv2d` / `QuantizedLinear`

```python
class QuantizedConv2d(nn.Module):
    def __init__(self, weight, bias, input_zero_point, output_zero_point,
                 input_scale, weight_scale, output_scale,
                 stride, padding, dilation, groups,
                 feature_bitwidth=8, weight_bitwidth=8):
        super().__init__()
        # 정수 텐서는 nn.Parameter로 직접 지원 안 됨 → register_buffer 사용
        self.register_buffer('weight', weight)
        self.register_buffer('bias', bias)
        self.register_buffer('weight_scale', weight_scale)
        # zero_point, scale은 파이썬 스칼라로 저장
        self.input_zero_point = input_zero_point
        self.output_zero_point = output_zero_point
        self.input_scale = input_scale
        self.output_scale = output_scale
        # 패딩을 (top, bottom, left, right) 형식으로 변환
        self.padding = (padding[1], padding[1], padding[0], padding[0])
        ...

    def forward(self, x):
        return quantized_conv2d(x, self.weight, self.bias, ...)
```

#### 전체 변환 흐름

```
nn.Conv2d + nn.ReLU (FP32)
        │
        ├── input activation range   (hook으로 기록)
        ├── output activation range  (hook으로 기록)
        ├── weight 양자화             (per-tensor or per-channel)
        └── bias 양자화               (per-channel, int32)
        │
        ▼
QuantizedConv2d (INT8)
 - weight: int8 텐서
 - bias:   int32 텐서 (Q_bias, shifted)
 - scale/zero_point: 저장된 파라미터
```

## 10. Non-uniform Quantization (K-means)

### 선형 양자화와의 차이

| | Linear Quantization | K-means Quantization |
|--|--|--|
| 양자화 방식 | 균일한 간격으로 매핑 | 데이터 분포에 맞춘 군집화 |
| 표현 | scale + zero_point | codebook (centroids + labels) |
| 저장 형태 | n-bit 정수 | 정수 인덱스 + FP32 centroid 테이블 |

### 도식 — K-means Quantization 개념

```
원본 가중치 분포:
[-0.48, -0.40, -0.20, 0.09, 0.11, 0.28, 0.32, 0.44]
          │
          ▼ K-means (k=4)
군집화:
Cluster0: [-0.48, -0.40]  → centroid: -0.44
Cluster1: [-0.20]         → centroid: -0.20
Cluster2: [0.09, 0.11]    → centroid:  0.10
Cluster3: [0.28, 0.32, 0.44] → centroid: 0.35
          │
          ▼ 코드북
labels:   [0, 0, 1, 2, 2, 3, 3, 3]   (2-bit 인덱스)
centroids: [-0.44, -0.20, 0.10, 0.35] (FP32)
          │
          ▼ 복원 (inference)
quantized_weight = centroids[labels]
= [-0.44, -0.44, -0.20, 0.10, 0.10, 0.35, 0.35, 0.35]
```

---

### 10-1. K-means 양자화 — `k_means_quantize`

```python
def k_means_quantize(fp32_tensor: torch.Tensor, bitwidth=4, codebook=None):
    if codebook is None:
        # 클러스터 수 = 2^bitwidth
        n_clusters = 2**bitwidth

        # K-means 실행 (fast_pytorch_kmeans 라이브러리)
        kmeans = KMeans(n_clusters=n_clusters, mode='euclidean', verbose=0)
        labels = kmeans.fit_predict(fp32_tensor.view(-1, 1)).to(torch.long)
        centroids = kmeans.centroids.to(torch.float).view(-1)
        codebook = Codebook(centroids, labels)

    # 코드북을 이용해 복원: centroids[labels] → FP32 텐서
    quantized_tensor = codebook.centroids[codebook.labels]

    # 원본 텐서를 quantized tensor로 in-place 업데이트
    fp32_tensor.set_(quantized_tensor.view_as(fp32_tensor))
    return codebook
```

#### 코드북 구조

```python
Codebook = namedtuple('Codebook', ['centroids', 'labels'])
# centroids: [n_clusters]   FP32 값 (군집 중심점)
# labels:    [n_elements]   정수 인덱스 (각 가중치가 속한 군집)
```

#### 복원 과정

```python
quantized_weight = codebook.centroids[codebook.labels].view_as(weight)
# 인덱스 → centroid 값으로 매핑
```

---

### 10-2. 전체 모델용 — `KMeansQuantizer`

```python
class KMeansQuantizer:
    def __init__(self, model: nn.Module, bitwidth=4):
        # 모델의 모든 weight를 K-means 양자화하고 codebook 저장
        self.codebook = KMeansQuantizer.quantize(model, bitwidth)

    @torch.no_grad()
    def apply(self, model, update_centroids):
        for name, param in model.named_parameters():
            if name in self.codebook:
                if update_centroids:
                    # QAT: 최신 가중치로 centroid 업데이트
                    update_codebook(param, codebook=self.codebook[name])
                # 현재 codebook 적용 (가중치를 centroid 값으로 복원)
                self.codebook[name] = k_means_quantize(param, codebook=self.codebook[name])

    @staticmethod
    @torch.no_grad()
    def quantize(model: nn.Module, bitwidth=4):
        codebook = dict()
        for name, param in model.named_parameters():
            if param.dim() > 1:  # weight만 양자화 (bias 제외)
                codebook[name] = k_means_quantize(param, bitwidth=bitwidth)
        return codebook
```

---

### 10-3. Codebook 업데이트 — `update_codebook`

```python
def update_codebook(fp32_tensor: torch.Tensor, codebook: Codebook):
    n_clusters = codebook.centroids.numel()
    fp32_tensor = fp32_tensor.view(-1)

    for k in range(n_clusters):
        # 같은 클러스터에 속하는 가중치들의 평균으로 centroid 업데이트
        codebook.centroids[k] = torch.mean(fp32_tensor[codebook.labels == k])
```

#### 수식

$$C_k = \frac{\sum_{j} W_j \cdot \mathbf{1}(I_j = k)}{\sum_{j} \mathbf{1}(I_j = k)}$$

- $C_k$: k번째 군집의 centroid
- $W_j$: j번째 가중치
- $I_j$: j번째 가중치의 클러스터 레이블
- $\mathbf{1}(\cdot)$: 지시함수

#### QAT에서의 역할

```
학습 1 iteration:
    forward → loss 계산 → backward → optimizer.step() → weight 업데이트
                                                              │
                                                              ▼
                                              update_codebook()  ← 새 weight로 centroid 갱신
                                                              │
                                                              ▼
                                              k_means_quantize()  ← 갱신된 codebook으로 weight 복원
```

## 11. PyTorch API를 이용한 Quantization

### 11-1. PTQ (Post-Training Quantization)

PyTorch의 `torch.quantization` API를 이용하면 4단계로 PTQ를 적용할 수 있습니다.

#### 전체 흐름

```
[1] Configuration
      model.qconfig = torch.quantization.default_qconfig
      ↓
[2] Prepare (Observer 삽입)
      prepared_model = torch.quantization.prepare(model)
      ↓
[3] Calibration (범위 관찰)
      for images, _ in trainloader:
          prepared_model(images)
          break
      ↓
[4] Convert (실제 양자화)
      quantized_model = torch.quantization.convert(prepared_model)
```

#### qconfig 구성 요소

```python
default_qconfig:
  weight observer:    MinMaxObserver (Per-tensor Symmetric)
  activation observer: MinMaxObserver (Per-tensor Asymmetric)
```

| 구성 요소 | PTQ 역할 |
|---|---|
| `qscheme` | Per-tensor / Per-channel, Symmetric / Asymmetric |
| `dtype` | 양자화 데이터 타입 (`torch.qint8`, `torch.quint8` 등) |
| `observer` | Min/Max 또는 히스토그램 기반 범위 측정 |

#### Prepare 단계에서 모델 변화

```python
# Before prepare:
Conv2d(3, 32, ...)

# After prepare:
Conv2d(3, 32, ...)
  (weight_fake_quant): MinMaxObserver(...)  ← observer 추가
  (activation_post_process): MinMaxObserver(...)  ← observer 추가
```

#### Convert 단계에서 모델 변화

```python
# Before convert:
Conv2d(3, 32, ...)  # FP32 레이어

# After convert:
QuantizedConv2d(3, 32, ...)  # INT8 레이어 (PyTorch 내장 구현)
```

---

### 11-2. QAT (Quantization-Aware Training)

#### PTQ vs QAT 비교

| 항목 | PTQ | QAT |
|------|-----|-----|
| 학습 필요 여부 | 불필요 | 필요 (fine-tuning) |
| Calibration | 필요 (일부 데이터) | 불필요 |
| 정확도 | 낮은 비트에서 손실 가능 | 손실 최소화 |
| 처리 시간 | 빠름 | 느림 (학습 필요) |
| `prepare()` 삽입 모듈 | Observer | Fake Quantizer |

#### QAT 흐름

```
[1] Configuration
      model.qconfig = torch.quantization.default_qat_qconfig
      ↓
[2] Prepare (Fake Quantizer 삽입)
      prepared_qat_model = torch.quantization.prepare(model)
      ↓
[3] Training (Fake Quantization으로 학습)
      for epoch in range(num_epochs):
          train(model, ...)  ← quantization error를 loss에 반영하며 학습
      ↓
[4] Convert (실제 양자화)
      qat_quantized_model = torch.quantization.convert(trained_qat_model)
```

#### Fake Quantizer 역할

```
학습 중:
  FP32 weight ─→ Fake Quantize ─→ 양자화된 척 한 FP32 값
                                       │
                                    backward 가능  ← STE (Straight-Through Estimator)
                                       │
                                 gradient 전달 → weight 업데이트

배포 시 (convert):
  Fake Quantizer 제거 + 실제 INT8 양자화 적용
```
