```
[ Teacher: VGGCifar9 ]                        [ Student: VGGCifar5 ]

    │                                          Conv3: 256→256

    │                                              │

 MaxPool (/2)  → 2×2
    │
 Global Avg Pool
 → (512,)
    │

    │
 출력: 10개 클래스 logits
 파라미터 수: ~약 9M (Teacher가 약 20배 이상 큼)
```

### 핵심 포인트: `forward()` 함수의 Global Average Pooling

```python
# Teacher/Student 공통
x = self.backbone(x)   # [B, C, H, W]
x = x.mean([2, 3])     # H, W 차원 평균 → [B, C]  ← Global Average Pooling!
x = self.classifier(x) # [B, 10]
```

- `x.mean([2, 3])` : 공간(H, W) 차원을 평균 내어 채널 벡터만 남김
- FC Layer 없이 분류 가능하게 해주는 경량화 기법

## 📌 3.1 Baseline 학습: `train()` 함수

### 역할
Teacher 모델의 도움 없이 **Cross-Entropy Loss만으로** Student를 독립 학습시킨 기준 성능(Baseline)을 측정한다.

### 코드 흐름

```python
def train(model, train_loader, epochs, learning_rate):
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=learning_rate)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, epochs * len(train_loader))

    model.train()  # 학습 모드 활성화 (Dropout, BN 등 활성화)

    for epoch in range(epochs):
        for inputs, labels in train_loader:
            inputs, labels = inputs.cuda(), labels.cuda()
            optimizer.zero_grad()        # 이전 grad 초기화
            outputs = model(inputs)      # 순전파
            loss = criterion(outputs, labels)  # CE Loss 계산
            loss.backward()             # 역전파
            optimizer.step()            # 파라미터 업데이트
            scheduler.step()            # 학습률 업데이트
```

### 학습률 스케줄러: `CosineAnnealingLR`

```
학습률 (lr)
  ^
  |****
  |    **
  |      **
  |        ****
  |            *****
  +-----------------------> Step (Epoch × Batch 수)
```

- 학습 초반에는 높은 lr로 빠르게 탐색, 후반에는 낮은 lr로 세밀하게 수렴
- `T_max = epochs * len(train_loader)` : 전체 배치 수 기준으로 주기 설정

### `test()` 함수

```python
def test(model, test_loader):
    model.eval()           # 평가 모드 (Dropout OFF, BN 고정)
    with torch.no_grad():  # 그래디언트 계산 비활성화 (메모리 절약)
        for inputs, labels in test_loader:
            outputs = model(inputs)
            _, predicted = torch.max(outputs.data, 1)  # 가장 높은 logit 클래스 선택
            correct += (predicted == labels).sum().item()
    accuracy = 100 * correct / total
```

- `torch.no_grad()` : 역전파 그래프를 생성하지 않아 메모리 효율적
- `torch.max(outputs, 1)` : 각 샘플에서 최대 logit 값의 인덱스(예측 클래스)를 반환

## 📌 3.2 Soft Targets KD: `train_knowledge_distillation()` 함수

### 핵심 아이디어

단순히 "정답 클래스만" 맞추는 CE Loss와 달리, **Teacher가 각 클래스에 부여한 확률 분포 자체**를 Student가 따라 학습한다.

예를 들어 고양이 이미지에 대해:
- Hard Label: `[0, 0, 1, 0, ...]` → "무조건 고양이"
- Teacher Soft Output: `[0.01, 0.05, 0.82, 0.08, ...]` → "고양이일 가능성 82%, 개 8%..."

Soft Output에는 **클래스 간 유사성 정보**가 담겨 있어, Student가 더 풍부한 지식을 학습할 수 있다.

### 전체 흐름 도식

```
입력 이미지 (batch)
       │
       ├────────────────────────┐
       ▼                        ▼
  [Teacher 모델]          [Student 모델]
  (eval, no_grad)         (train mode)
       │                        │
  teacher_logits          student_logits
       │                        │
  softmax(/ T)            softmax(/ T)
       │                        │
  soft_targets            student_prob
       │                        │
       └──────────┬─────────────┘
                  ▼
          KL Divergence 계산
        (soft_targets_loss)
                  │
       labels ───►│─── CE Loss
                  │    (label_loss)
                  ▼
     α * soft_targets_loss + β * label_loss
                  │
             loss.backward()
                  │
         Student 파라미터 업데이트
```

### Temperature(T)의 역할

```python
soft_targets = nn.functional.softmax(teacher_logits / T, dim=-1)
```

```
T = 1 (기본):   [0.01, 0.05, 0.82, 0.08, ...]  ← 날카로운 분포 (정보 적음)
T = 10 (높음):  [0.08, 0.10, 0.45, 0.15, ...]  ← 완만한 분포 (정보 풍부)
```

- T가 높을수록 소수 클래스의 확률 차이도 Student에게 전달됨
- 논문 저자(Hinton)는 학습 시 T를 높게 설정하고, 추론 시에는 T=1로 복귀

### Soft Target Loss 계산 (KL Divergence)

```python
soft_targets_loss = torch.sum(
    soft_targets * (soft_targets.log() - student_prob.log())
) / student_prob.size(0) * (T**2)
```

이 수식은 **KL Divergence**를 수동으로 계산한 것:

```
KL(P || Q) = Σ P(i) * log(P(i) / Q(i))
           = Σ P(i) * (log P(i) - log Q(i))

여기서 P = soft_targets (Teacher),  Q = student_prob (Student)
```

- `T**2` 스케일링: T로 나눈 logit으로 softmax를 계산하면 gradient가 1/T² 배 작아지므로, 이를 보상하기 위해 T² 곱

### 최종 Loss 결합

```python
loss = soft_target_loss_weight * soft_targets_loss + ce_loss_weight * label_loss
#      α (예: 0.5)                                    β (예: 0.5)
```

| 파라미터 | 의미 | 효과 |
|---|---|---|
| `T` | Temperature | 클수록 부드러운 분포 → 더 많은 inter-class 관계 학습 |
| `soft_target_loss_weight (α)` | KD loss 가중치 | 클수록 Teacher 모방 강도 증가 |
| `ce_loss_weight (β)` | CE loss 가중치 | 클수록 정답 레이블 기반 학습 강조 |

## 📌 3.3 Cosine Loss KD: `train_cosine_loss()` 함수

### 핵심 아이디어

Soft Target KD가 **출력 확률 분포(logit 공간)** 를 맞추는 방식이라면, Cosine Loss KD는 **중간 feature 벡터의 방향(representation 공간)** 을 맞추는 방식이다.

```
Soft Target KD:  [출력단] logit 분포를 Teacher에 맞춤
Cosine Loss KD:  [중간단] feature 벡터 방향을 Teacher에 맞춤
```

### 모델 구조 변경: `VGGCifar9_Cosine` / `VGGCifar5_Cosine`

기존 모델에서 `forward()`가 logit 하나만 반환했다면, Cosine 모델은 **logit + feature 벡터** 두 가지를 반환한다.

#### Teacher (`VGGCifar9_Cosine`) forward:

```python
def forward(self, x):
    x = self.backbone(x)                         # [B, 512, 2, 2]
    conv_output = torch.flatten(x, 1)            # [B, 512×2×2] = [B, 2048]
    conv_output_after_pooling = torch.nn.functional.avg_pool1d(
        conv_output, 2                           # [B, 1024]  ← Student 크기에 맞게 절반으로 축소
    )
    x = x.mean([2, 3])                           # [B, 512]
    x = self.classifier(x)                       # [B, 10]
    return x, conv_output_after_pooling          # (logits, feature 벡터)
```

#### Student (`VGGCifar5_Cosine`) forward:

```python
def forward(self, x):
    x = self.backbone(x)             # [B, 256, 2, 2]
    conv_output = torch.flatten(x, 1)  # [B, 256×2×2] = [B, 1024]  ← Teacher와 동일 차원!
    x = x.mean([2, 3])               # [B, 256]
    x = self.classifier(x)           # [B, 10]
    return x, conv_output            # (logits, feature 벡터)
```

#### 차원 맞추기 핵심

```
Teacher backbone 출력: [B, 512, 2, 2]
  → flatten: [B, 2048]
  → avg_pool1d(kernel=2): [B, 1024]  ← 절반으로

Student backbone 출력: [B, 256, 2, 2]
  → flatten: [B, 1024]               ← 동일!
```

`avg_pool1d(conv_output, 2)` 는 1D 평균 풀링으로 Teacher의 feature 차원을 Student와 동일하게 맞춰준다.

### CosineEmbeddingLoss 계산

```python
cosine_loss = nn.CosineEmbeddingLoss()
hidden_rep_loss = cosine_loss(
    student_hidden_representation,  # Student feature 벡터 [B, 1024]
    teacher_hidden_representation,  # Teacher feature 벡터 [B, 1024]
    target=torch.ones(inputs.size(0)).cuda()  # 모든 샘플에 대해 target=+1
)
```

**CosineEmbeddingLoss 수식:**

```
target = +1 인 경우:
  Loss = 1 - cos(student_vec, teacher_vec)

target = -1 인 경우:
  Loss = max(0, cos(student_vec, teacher_vec) - margin)
```

- `target=+1` → 두 벡터를 최대한 유사하게(같은 방향으로) 만드는 방향으로 학습
- cos = 1이면 Loss = 0 (완벽히 같은 방향)
- cos = 0이면 Loss = 1 (직교, 관계 없음)
- cos = -1이면 Loss = 2 (반대 방향)

### 전체 흐름 도식

```
입력 이미지 (batch)
       │
       ├────────────────────────────┐
       ▼                            ▼
  [Teacher_Cosine]           [Student_Cosine]
  (eval, no_grad)             (train mode)
       │                            │
  logits,                     student_logits,
  teacher_hidden_rep          student_hidden_rep
  [B, 1024]                   [B, 1024]
       │                            │
       └──────────┬─────────────────┘
                  ▼
       CosineEmbeddingLoss(target=1)
         (hidden_rep_loss)
                  │
       labels ───►│─── CE Loss (label_loss)
                  ▼
  α * hidden_rep_loss + β * label_loss
                  │
         Student 파라미터 업데이트
```

## 📌 3.4 Intermediate Regressor KD: `train_mse_loss()` 함수

### 핵심 아이디어

Cosine KD가 flatten된 1D 벡터의 방향 유사성을 맞춘다면, Regressor KD는 **2D feature map(공간 정보 포함)** 을 직접 Teacher 수준으로 맞추는 방식이다. 단, Teacher와 Student의 채널 수가 달라 직접 비교 불가능하므로 **trainable regressor 레이어**로 채널을 업스케일링한다.

```
Cosine KD:   flatten된 벡터의 방향 유사성 (공간 정보 무시)
Regressor KD: 2D feature map의 픽셀 값 자체를 MSE로 일치시킴 (공간 정보 보존)
```

### 문제: Teacher/Student feature map 채널 불일치

```
Teacher backbone 출력: [B, 512, 2, 2]   ← 채널 512
Student backbone 출력: [B, 256, 2, 2]   ← 채널 256  ← 직접 비교 불가!
```

### 해결책: Regressor 레이어 추가

`VGGCifar5_Regressor`에 **1개의 Conv 레이어(regressor)** 를 추가하여 Student의 feature map 채널을 256 → 512로 확장:

```python
# VGGCifar5_Regressor 내부
self.regressor = nn.Sequential(
    nn.Conv2d(256, 512, 3, padding=1, bias=False),  # 256→512 채널 업스케일
    nn.BatchNorm2d(512)
)
```

```python
def forward(self, x):
    x = self.backbone(x)          # [B, 256, 2, 2]
    regressor_output = self.regressor(x)  # [B, 512, 2, 2]  ← Teacher와 동일!
    x = x.mean([2, 3])            # [B, 256]
    x = self.classifier(x)        # [B, 10]
    return x, regressor_output    # (logits, 변환된 feature map)
```

> **주의**: regressor는 **분류 성능**에는 영향을 주지 않는다. Teacher의 feature map을 모방하도록 학습되는 별도 경로다.

### Teacher 모델 (`VGGCifar9_Regressor`) forward:

```python
def forward(self, x):
    x = self.backbone(x)       # [B, 512, 2, 2]
    conv_feature_map = x       # feature map을 그대로 저장
    x = x.mean([2, 3])         # [B, 512]
    x = self.classifier(x)     # [B, 10]
    return x, conv_feature_map # (logits, feature map)
```

### MSE Loss 계산

```python
mse_loss = nn.MSELoss()
hidden_rep_loss = mse_loss(regressor_feature_map, teacher_feature_map)
#                          Student 변환 결과          Teacher 중간 결과
#                          [B, 512, 2, 2]             [B, 512, 2, 2]
```

**MSELoss 수식:**
```
MSE = (1/N) * Σ (teacher_feat[i] - student_regressed_feat[i])²
```

- 두 feature map의 모든 픽셀 값의 평균 제곱 오차를 최소화
- CosineEmbeddingLoss와 달리 **크기와 방향 모두** 맞추도록 유도

### 전체 흐름 도식

```
입력 이미지 (batch)
       │
       ├──────────────────────────────────┐
       ▼                                  ▼
  [Teacher_Regressor]            [Student_Regressor]
  (eval, no_grad)                  (train mode)
       │                                  │
  teacher_feature_map          backbone output [B,256,2,2]
  [B, 512, 2, 2]                           │
       │                           regressor (Conv 256→512)
       │                                  │
       │                          regressor_feature_map
       │                          [B, 512, 2, 2]
       │                                  │
       └──────────┬───────────────────────┘
                  ▼
          MSELoss(regressed, teacher)
          (hidden_rep_loss)
                  │
       labels ───►│─── CE Loss (label_loss)
                  ▼
  α * hidden_rep_loss + β * label_loss
                  │
    Student(+regressor) 파라미터 업데이트
```

## 📊 4가지 KD 방식 전체 비교

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     Knowledge Distillation 방식 비교                     │
│                                                                         │
│  ① Baseline (CE Only)                                                   │
│  ┌─────────┐                  ┌─────────┐                               │
│  │ Teacher │  (사용 안 함)     │ Student │──► CE Loss                   │
│  └─────────┘                  └─────────┘                               │
│                                                                         │
│  ② Soft Target KD                                                       │
│  ┌─────────┐   softmax(/ T)   ┌─────────┐                               │
│  │ Teacher │──────────────────│ Student │──► α*KL Loss + β*CE Loss      │
│  │  logits │   soft targets   │  logits │                               │
│  └─────────┘                  └─────────┘                               │
│                                                                         │
│  ③ Cosine Loss KD                                                       │
│  ┌─────────┐  flatten+pool1d  ┌─────────┐                               │
│  │ Teacher │──────────────────│ Student │──► α*CosineEmbedLoss+β*CE    │
│  │ feature │  [B, 1024]       │ feature │                               │
│  │  vector │                  │ vector  │                               │
│  └─────────┘                  └─────────┘                               │
│                                                                         │
│  ④ Regressor + MSE KD                                                   │
│  ┌─────────┐  feature map     ┌─────────┐                               │
│  │ Teacher │──────────────────│ Student │──► α*MSE Loss + β*CE Loss    │
│  │[B,512,  │  [B, 512, 2, 2]  │backbone │                               │
│  │  2, 2]  │                  │+Conv    │                               │
│  └─────────┘                  │regressor│                               │
│                                └─────────┘                               │
└─────────────────────────────────────────────────────────────────────────┘
```

| 구분 | 학습 대상 | 사용 Loss | 모델 변경 | 공간 정보 |
|---|---|---|---|---|
| **Baseline** | 정답 레이블만 | CE | 없음 | - |
| **Soft Target KD** | Teacher 출력 분포 | KL + CE | 없음 | ✗ |
| **Cosine KD** | feature 벡터 방향 | Cosine + CE | Teacher: avg_pool1d 추가 | ✗ (flatten) |
| **Regressor KD** | feature map 자체 | MSE + CE | Student: regressor 추가 | ✅ (2D 보존) |

## 🔑 핵심 개념 요약

### 1. Temperature Scaling (온도 스케일링)

```python
# T=1: 기본 softmax (sharp)
softmax([3.0, 1.0, 0.5]) → [0.73, 0.18, 0.09]

# T=5: 부드러운 분포 (soft)
softmax([3.0/5, 1.0/5, 0.5/5]) → [0.46, 0.30, 0.24]
```

T가 높을수록 작은 클래스 확률도 Student에게 전달 → **"dark knowledge"** 학습

### 2. T² 스케일링의 이유

KD loss에서 logit을 T로 나누면 gradient의 크기가 `1/T²`배가 된다.
따라서 CE Loss와 비슷한 스케일을 유지하려면 `T²`를 곱해서 보상해야 한다.

```python
soft_targets_loss = torch.sum(
    soft_targets * (soft_targets.log() - student_prob.log())
) / student_prob.size(0) * (T**2)   # ← T² 보상
```

### 3. `teacher.eval()` 이 반드시 필요한 이유

| 항목 | train() | eval() |
|---|---|---|
| BatchNorm | 배치 통계 업데이트 O | 저장된 통계 사용 (고정) |
| Dropout | 랜덤 뉴런 OFF | 전체 뉴런 사용 |
| gradient | 계산 O | (no_grad 함께 사용) |

Teacher는 학습이 완료된 기준 모델이므로, 가중치/통계가 변하면 안 된다.
`eval()` + `torch.no_grad()` 조합으로 완전히 고정시킨다.

### 4. Loss 가중치 α, β 선택 전략

```
soft_target_loss_weight (α) = 0.5
ce_loss_weight (β)          = 0.5

→ α + β = 1.0 이 일반적이나 필수는 아님
→ α 증가: Teacher 모방 강도 ↑, 정답 레이블 반영 ↓
→ β 증가: 정답 레이블 중심 학습, Teacher 영향 ↓
```
