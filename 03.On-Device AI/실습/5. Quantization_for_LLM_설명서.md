## 1. 균일 양자화(Uniform Quantization) 수식 이해

모든 양자화 구현의 기반이 되는 수식.

```
실수 범위 [β, α]  →  정수 범위 [0, 2^b - 1]
```

| 기호 | 의미 |
|------|------|
| `b` | 비트 수 (e.g., 4-bit, 8-bit) |
| `α` | 최대값 (max) |
| `β` | 최소값 (min) |
| `s_q` | 스케일 (scale) |
| `z` | 제로포인트 (zero point) |
| `w_q` | 양자화된 정수 weight |

```
(1) s_q = (α - β) / (2^b - 1)
(2) z   = Round(-β / s_q)
(3) w_q = Clamp( Round(w / s_q) + z ,  0,  2^b - 1 )
```

**복원 (Dequantization)**:
```
w_dq = (w_q - z) * s_q
```

## Part 1 — Weight-only Quantization (AWQ)

---

### 1-1. `pseudo_quantize_tensor`

> **역할**: Weight 텐서를 `b`-bit로 양자화한 뒤 즉시 FP16으로 복원(dequantize)하여, 실제 정수 저장 없이 양자화 효과를 시뮬레이션.

```python
def pseudo_quantize_tensor(w, n_bit=4, q_group_size=-1):
    org_w_shape = w.shape

    # [Step 1] Group Quantization: 행 방향으로 그룹 재구성
    if q_group_size > 0:
        w = w.reshape(-1, q_group_size)  # (N, q_group_size)

    # [Step 2] 각 행(그룹)별 최대/최소값 계산
    max_val = w.amax(dim=1, keepdim=True)   # α
    min_val = w.amin(dim=1, keepdim=True)   # β
    max_int = 2 ** n_bit - 1               # 정수 최대값

    # [Step 3] Scale 및 Zero Point 계산
    scales = (max_val - min_val).clamp(min=1e-5) / max_int
    zeros  = (-torch.round(min_val / scales)).clamp_(0, max_int)

    # [Step 4] Quantize: 실수 → 정수
    w = torch.clamp(torch.round(w / scales) + zeros, 0, max_int)

    # [Step 5] Dequantize: 정수 → 실수 (pseudo!)
    w = (w - zeros) * scales

    return w.reshape(org_w_shape)
```

**데이터 흐름 도식**:

```
원본 FP16 Weight
        │
        ▼
[그룹 분할] q_group_size=128이면 (N×128) 형태로 reshape
        │
        ▼
[Scale/Zero 계산]
  s = (max - min) / (2^n_bit - 1)
  z = round(-min / s)
        │
        ▼
[Quantize]
  w_q = clamp( round(w/s) + z ,  0,  2^n_bit-1 )
        │
        ▼
[Dequantize]
  w_dq = (w_q - z) * s
        │
        ▼
복원된 FP16 Weight (양자화 오차 포함)
```

> **핵심 포인트**: 실제로는 정수 저장을 하지 않는다. 양자화 후 즉시 복원하여 "양자화를 거쳤을 때 얼마나 정확도가 떨어지는가"를 FP16 공간에서 측정하는 것이 목적.

### 1-2. `pseudo_quantize_model_weight`

> **역할**: 모델 내 모든 `nn.Linear` 레이어의 weight에 `pseudo_quantize_tensor`를 일괄 적용.

```python
@torch.no_grad()
def pseudo_quantize_model_weight(model, w_bit, q_group_size):
    for n, m in model.named_modules():
        if isinstance(m, nn.Linear):
            m.weight.data = pseudo_quantize_tensor(
                m.weight.data, n_bit=w_bit, q_group_size=q_group_size
            )
```

간단하지만, 모든 Linear layer를 순회하며 weight만 교체하는 패턴은 이후 모든 양자화 함수에서 반복되므로 기억해 두어야 함.

### 1-3. `get_calib_dataset` / `get_calib_feat`

> **역할**: AWQ의 핵심 아이디어인 "어느 채널이 중요한가?"를 파악하기 위해, 실제 입력 데이터를 모델에 흘려보내며 각 Linear layer 입력의 평균 절댓값(activation scale)을 수집.

#### `get_calib_dataset`

```python
def get_calib_dataset(tokenizer, n_samples=256, block_size=512):
    # Pile 데이터셋 로드 후 셔플
    dataset = load_dataset("mit-han-lab/pile-val-backup", split="validation").shuffle(seed=42)
    
    samples = []
    for data in dataset:
        line_encoded = tokenizer.encode(data["text"].strip())
        if len(line_encoded) > block_size:   # 너무 긴 문장 제외
            continue
        samples.append(torch.tensor([line_encoded]))
        if len(samples) == n_samples:
            break
    
    cat = torch.cat(samples, dim=1)               # 전체 연결
    n_split = cat.shape[1] // block_size          # block_size 단위로 분할
    return [cat[:, i*block_size:(i+1)*block_size] for i in range(n_split)]
```

#### `get_calib_feat`

```python
@torch.no_grad()
def get_calib_feat(model, tokenizer):
    input_dict = {}

    def stat_input_max_hook(m, x, y, name):
        if isinstance(x, tuple): x = x[0]
        # (batch*seq_len, hidden_dim) → hidden_dim별 평균 절댓값 계산
        x_max = x.view(-1, x.shape[-1]).abs().mean(dim=0).cpu().detach()
        if name not in input_dict:
            input_dict[name] = [x_max]
        else:
            input_dict[name] += [x_max]

    # 모든 Linear layer에 forward hook 등록
    hooks = [m.register_forward_hook(partial(stat_input_max_hook, name=n))
             for n, m in model.named_modules() if isinstance(m, nn.Linear)]

    # calibration 데이터 통과 → hook이 자동으로 통계 수집
    for input_ids in get_calib_dataset(tokenizer):
        model(input_ids.to(device))

    for hook in hooks: hook.remove()
    return input_dict  # { layer_name: [activation_scale_batch1, ...] }
```

**동작 도식**:

```
Calibration Data (256 samples)
         │
         ▼
  [Forward Pass]
         │
    ┌────┴──────────────────────────┐
    │  Linear Layer (각각에 Hook)    │
    │                               │
    │  입력 x → |x|.mean(dim=0)     │
    │        → 채널별 평균 절댓값    │
    └────────────────────────────────┘
         │
         ▼
input_dict = {
  "model.decoder.layers.0.self_attn.q_proj": [scale_batch1, ...],
  "model.decoder.layers.0.fc1": [scale_batch1, ...],
  ...
}
```

> **핵심 포인트**: AWQ는 "activation이 큰 채널 = 중요한 채널"이라는 가정에 기반. 이 함수가 채널 중요도를 측정하는 역할을 한다.

### 1-4. `pseudo_quantize_model_weight_scaleup` (실습 1 — Salient Channel Scaling)

> **역할**: activation이 큰 상위 1% 채널(salient channel)을 scale-up → 양자화 → scale-down하여, FP16으로 유지하지 않아도 중요한 채널의 정보를 보존.

```python
@torch.no_grad()
def pseudo_quantize_model_weight_scaleup(model, w_bit, q_group_size, input_feat, scale_factor):
    for n, m in model.named_modules():
        if isinstance(m, nn.Linear):
            importance = sum(input_feat[n]).float()    # 채널별 activation 합산
            num_salient = int(len(importance) * 0.01) # 상위 1% 개수

            # Step 1: 상위 1% 채널 인덱스 추출
            outlier_mask = torch.topk(importance, num_salient)[1]

            # Step 2: 중요 채널 weight를 scale_factor배 확대
            m.weight.data[:, outlier_mask] *= scale_factor

            # Step 3: 양자화 적용 (확대된 weight가 더 정밀하게 표현됨)
            m.weight.data = pseudo_quantize_tensor(m.weight.data, n_bit=w_bit, q_group_size=q_group_size)

            # Step 4: 다시 scale_factor로 나누어 복원 (pseudo이므로)
            m.weight.data[:, outlier_mask] /= scale_factor
```

**AWQ Scale-up 원리**:

```
Linear 연산:  y = W · x

양자화 오차:
  Err( Q(W) · x ) = Δ · RoundErr(W/Δ) · x
       ↕
  Err( Q(W·s) · (x/s) ) = Δ · RoundErr(W/Δ) · x · (1/s)

  → s > 1 이면 오차가 줄어든다!

단, s가 너무 크면 그룹 내 Δ(scale)가 함께 커져서 다른 채널에 악영향
→ 최적 s를 찾아야 함
```

**scale_factor에 따른 perplexity 변화 (개념도)**:

```
Perplexity
     │
  높음│ ★ (scale=1, 보정 없음)
     │  \
     │   \        ★ (scale 너무 큼, 다른 채널에 악영향)
     │    ★ (최적 scale)
  낮음│
     └──────────────────────── scale_factor
        1    1.5    2   2.5    3
```

### 1-5. `scale_ln_fcs` / `scale_fc_fc` (Scale 조정 유틸)

> **역할**: LayerNorm ↔ Linear, 또는 Linear ↔ Linear 사이의 scale을 실제 파라미터에 반영하는 유틸 함수.

#### `scale_ln_fcs` — LayerNorm과 후속 FC들 간 scale 조정

```python
@torch.no_grad()
def scale_ln_fcs(ln, fcs, scales):
    # LayerNorm weight/bias를 scale로 나눔 → 출력 분포 축소
    ln.weight.div_(scales)
    if ln.bias is not None:
        ln.bias.div_(scales)

    # 후속 Linear weight를 scale로 곱함 → 입력 분포 확대로 상쇄
    for fc in fcs:
        fc.weight.mul_(scales.view(1, -1))
```

```
변환 전:  x → [LayerNorm(γ)] → [Linear(W)] → y
변환 후:  x → [LayerNorm(γ/s)] → [Linear(W·s)] → y   (수학적으로 동치)
```

#### `scale_fc_fc` — 연속된 두 Linear 간 scale 조정

```python
@torch.no_grad()
def scale_fc_fc(fc1, fc2, scales):
    # fc1 출력 채널을 scale로 나눔 → 출력 분포 축소
    fc1.weight[-scales.size(0):].div_(scales.view(-1, 1))
    if fc1.bias is not None:
        fc1.bias.div_(scales.view(-1))

    # fc2 입력 채널을 scale로 곱함 → 분포 복원
    fc2.weight.mul_(scales.view(1, -1))
```

```
변환 전:  ... → [fc1] → [fc2] → ...
변환 후:  ... → [fc1/s] → [fc2·s] → ...   (수학적으로 동치)
```

### 1-6. `auto_scale_block` / `pseudo_quantize_model_weight_auto_scale` (실습 2 — 자동 Scale 탐색)

> **역할**: 각 Transformer 블록 내에서 최적 scale factor α를 자동으로 탐색하여 적용. Grid search로 `s = s_X^α` 형태의 best α를 찾음.

**수식**:
```
L(s) = ‖ Q(W·s) · (s⁻¹·X) − W·X ‖

s = s_X^α,   s_X = ‖X‖₁   (activation의 채널별 평균 절댓값)

α* = argmin_α L(s_X^α)
```

```python
@torch.no_grad()
def auto_scale_block(module, name, w_bit, q_group_size, input_feat):

    def _search_module_scale(block, linears2scale, x, kwargs={}):
        org_out = block(x, **kwargs)               # 원본 출력 저장
        s_x = x.view(-1, x.shape[-1]).abs().mean(0).clamp(1e-5)  # activation scale

        best_error = torch.inf
        best_scales = 0

        for ratio in range(20):             # α를 0/20, 1/20, ..., 19/20 으로 탐색
            alpha = ratio / 20
            scales = s_x ** alpha           # s = s_X^α
            scales = scales / (scales.max() * scales.min()).sqrt()  # 정규화

            for fc in linears2scale:
                fc.weight.mul_(scales)      # weight에 scale 적용
                fc.weight.data = pseudo_quantize_tensor(fc.weight.data, w_bit, q_group_size)
                fc.weight.data /= scales    # pseudo이므로 다시 복원

            out = block(x, **kwargs)
            loss = (org_out - out).float().pow(2).mean().item()  # MSE 오차 계산

            if loss < best_error:
                best_error, best_scales = loss, scales

            block.load_state_dict(org_sd)   # 탐색 후 원래 state 복원

        return best_scales

    # (1) Self-Attention Q/K/V projection
    qkv = [module.self_attn.q_proj, module.self_attn.k_proj, module.self_attn.v_proj]
    final_scales = _search_module_scale(module.self_attn, qkv, inp)
    scale_ln_fcs(module.self_attn_layer_norm, qkv, final_scales)

    # (2) Attention out_proj
    final_scales = _search_module_scale(module.self_attn.out_proj, [module.self_attn.out_proj], inp)
    scale_fc_fc(module.self_attn.v_proj, module.self_attn.out_proj, final_scales)

    # (3) FFN fc1
    final_scales = _search_module_scale(module.fc1, [module.fc1], inp)
    scale_ln_fcs(module.final_layer_norm, module.fc1, final_scales)

    # (4) FFN fc2
    final_scales = _search_module_scale(module.fc2, [module.fc2], inp)
    scale_fc_fc(module.fc1, module.fc2, final_scales)
```

**자동 scale 탐색 흐름**:

```
각 Transformer Block
    │
    ├─[Attention 부분]─────────────────────────────────────
    │  입력 x (calibration)
    │    ↓
    │  s_X = mean(|x|, dim=0)       ← 채널별 activation 크기
    │    ↓
    │  α ∈ {0, 0.05, 0.10, ..., 0.95}  ← Grid search
    │    ↓
    │  scales = s_X^α / normalize
    │    ↓
    │  W_temp = Q(W * scales) / scales  (pseudo quantize with scale)
    │    ↓
    │  MSE( original_output, scaled_output ) → best α 선택
    │    ↓
    │  scale_ln_fcs(LayerNorm, [Q,K,V], best_scales)  ← 파라미터에 영구 반영
    │
    └─[FFN 부분]──────────────────── (동일 패턴 반복)
```

## Part 2 — Weight & Activation Quantization (SmoothQuant)

---

### 2-1. 양자화 기본 함수들

> **역할**: weight와 activation 각각을 per-channel 또는 per-tensor 방식으로 absmax 기반 양자화.

**`Symmetric Quantization` 수식 (SmoothQuant에서 사용)**:
```
scale = max(|w|) / (2^(n_bits-1) - 1)
w_q   = round(w / scale) * scale       ← pseudo (in-place)
```

> AWQ(asymmetric: min~max 범위)와 달리 SmoothQuant는 **symmetric** (0 중심, zero-point 없음).

#### Weight Quantization

```python
# Per-Channel: 출력 채널(행)별로 독립 스케일
def quantize_weight_per_channel_absmax(w, n_bits=8):
    scales = w.abs().max(dim=-1, keepdim=True)[0]   # 행별 최대 절댓값
    q_max  = 2 ** (n_bits - 1) - 1                 # e.g., 127 for int8
    scales.clamp_(min=1e-5).div_(q_max)             # scale = absmax / q_max
    w.div_(scales).round_().mul_(scales)            # quantize → dequantize
    return w

# Per-Tensor: 전체 텐서 하나의 스케일
def quantize_weight_per_tensor_absmax(w, n_bits=8):
    scales = w.abs().max()                          # 전체 최대 절댓값
    q_max  = 2 ** (n_bits - 1) - 1
    scales.clamp_(min=1e-5).div_(q_max)
    w.div_(scales).round_().mul_(scales)
    return w
```

#### Activation Quantization

```python
# Per-Token: 토큰(시퀀스 위치)별로 독립 스케일
def quantize_activation_per_token_absmax(t, n_bits=8):
    scales = t.abs().max(dim=-1, keepdim=True)[0]   # 토큰별 최대 절댓값
    q_max  = 2 ** (n_bits - 1) - 1
    scales.clamp_(min=1e-5).div_(q_max)
    t.div_(scales).round_().mul_(scales)
    return t

# Per-Tensor: 전체 텐서 하나의 스케일
def quantize_activation_per_tensor_absmax(t, n_bits=8):
    scales = t.abs().max()
    q_max  = 2 ** (n_bits - 1) - 1
    scales.clamp_(min=1e-5).div_(q_max)
    t.div_(scales).round_().mul_(scales)
    return t
```

**Per-Channel vs Per-Tensor vs Per-Token 비교**:

```
Weight (Out×In 행렬):
┌──────────────────────────────────────────────┐
│ Per-Channel: 각 행마다 다른 scale            │
│   [채널0] scale_0: 0.08  [● ● ● ● ● ● ● ●] │
│   [채널1] scale_1: 0.03  [● ● ● ● ● ● ● ●] │
│   [채널2] scale_2: 0.15  [● ● ● ● ● ● ● ●] │
│                                               │
│ Per-Tensor: 전체에 scale 하나                │
│             scale: 0.15  [전체 동일 기준]    │
└──────────────────────────────────────────────┘

Activation (Batch×Seq×Hidden):
┌──────────────────────────────────────────────┐
│ Per-Token: 각 토큰 위치마다 다른 scale       │
│   [Token0] scale_t0  [● ● ● ● ● ●]          │
│   [Token1] scale_t1  [● ● ● ● ● ●]          │
│                                               │
│ Per-Tensor: 전체에 scale 하나                │
│             scale: max_all                   │
└──────────────────────────────────────────────┘
```

### 2-2. `W8A8Linear` 클래스

> **역할**: FP16 `nn.Linear`를 8-bit weight + 8-bit activation으로 동작하도록 래핑. 실제 연산은 FP16이지만, forward 시 quantize → linear → (optional) quantize로 W8A8 효과 시뮬레이션.

```python
class W8A8Linear(nn.Module):
    def __init__(self, in_features, out_features, bias=True,
                 act_quant="per_token", quantize_output=False, quantize_bits=8):
        super().__init__()
        # weight는 FP16 buffer로 보관
        self.register_buffer("weight", torch.randn(..., dtype=torch.float16))

        # activation quantization 방식 선택
        if act_quant == "per_token":
            self.act_quant = partial(quantize_activation_per_token_absmax, n_bits=8)
        elif act_quant == "per_tensor":
            self.act_quant = partial(quantize_activation_per_tensor_absmax, n_bits=8)

        # 출력 quantization (BMM 입력용, e.g., Q·K^T 계산 전)
        self.output_quant = self.act_quant if quantize_output else lambda x: x

    @torch.no_grad()
    def forward(self, x):
        q_x = self.act_quant(x)                              # ① activation 양자화
        y   = F.linear(q_x, self.weight, self.bias)          # ② FP16 Linear 연산
        q_y = self.output_quant(y)                           # ③ 출력 양자화 (선택)
        return q_y

    @staticmethod
    def from_float(module, weight_quant="per_channel", act_quant="per_token",
                   quantize_output=False, quantize_bits=8):
        # 기존 nn.Linear를 W8A8Linear로 변환
        new_module = W8A8Linear(module.in_features, module.out_features, ...)

        if weight_quant == "per_channel":
            new_module.weight = quantize_weight_per_channel_absmax(module.weight, n_bits=8)
        elif weight_quant == "per_tensor":
            new_module.weight = quantize_weight_per_tensor_absmax(module.weight, n_bits=8)

        if module.bias is not None:
            new_module.bias = module.bias
        return new_module
```

**W8A8Linear Forward 흐름**:

```
입력 x (FP16)
     │
     ▼
[act_quant]  ← quantize_activation_per_token/tensor_absmax
  x → q_x (8-bit로 round한 뒤 다시 FP16 복원)
     │
     ▼
[F.linear(q_x, W_int8, bias)]  ← W_int8도 실제론 FP16에 저장된 pseudo
     │
     ▼
[output_quant]  ← BMM 입력에 필요한 경우 (q_proj, k_proj, v_proj)
     │
     ▼
출력 q_y (FP16)
```

### 2-3. `quantize_opt`

> **역할**: OPT 모델의 모든 FFN (fc1, fc2) 및 Attention (q/k/v/out_proj) Linear layer를 `W8A8Linear`로 교체.

```python
def quantize_opt(model, weight_quant="per_tensor", act_quant="per_tensor",
                 quantize_bmm_input=True, quantize_bits=8):
    for name, m in model.model.named_modules():
        if isinstance(m, OPTDecoderLayer):
            # FFN 계층
            m.fc1 = W8A8Linear.from_float(m.fc1, weight_quant, act_quant, ...)
            m.fc2 = W8A8Linear.from_float(m.fc2, weight_quant, act_quant, ...)

        elif isinstance(m, OPTAttention):
            # Q, K, V projection (quantize_output=True → BMM 입력도 양자화)
            m.q_proj = W8A8Linear.from_float(m.q_proj, ..., quantize_output=quantize_bmm_input)
            m.k_proj = W8A8Linear.from_float(m.k_proj, ..., quantize_output=quantize_bmm_input)
            m.v_proj = W8A8Linear.from_float(m.v_proj, ..., quantize_output=quantize_bmm_input)
            m.out_proj = W8A8Linear.from_float(m.out_proj, weight_quant, act_quant, ...)
    return model
```

**교체 대상 도식 (OPT Decoder Layer)**:

```
OPTDecoderLayer
 │
 ├─ self_attn_layer_norm
 │
 ├─ self_attn (OPTAttention)
 │    ├─ q_proj  [Linear → W8A8Linear, quantize_output=True]
 │    ├─ k_proj  [Linear → W8A8Linear, quantize_output=True]
 │    ├─ v_proj  [Linear → W8A8Linear, quantize_output=True]
 │    └─ out_proj [Linear → W8A8Linear]
 │
 ├─ final_layer_norm
 │
 ├─ fc1 [Linear → W8A8Linear]
 └─ fc2 [Linear → W8A8Linear]
```

### 2-4. SmoothQuant 핵심 원리

**문제**: Activation에 outlier가 존재 → Activation 양자화 오차가 커짐.

```
기존 연산:  Y = X · W

Activation X (per-token):  대부분 작지만, 특정 채널은 매우 큼 (outlier!)
Weight W (per-channel):    비교적 균일

→ 이 비대칭성이 W8A8 양자화의 정확도를 떨어뜨림
```

**SmoothQuant 해결책**:

```
Y = X · W
  = (X · diag(s)⁻¹) · (diag(s) · W)
  = X̂ · Ŵ

where s = 스케일 팩터 벡터 (채널별)

→ X̂ = X / s : activation의 채널별 스케일 조정 (outlier 완화)
→ Ŵ = s · W : weight에 스케일 적용 (양자화 난이도가 weight로 이전)
```

**파라미터 관점에서의 구현**:
```
LayerNorm(γ) → [FC(W)]  구조에서

LayerNorm.weight /= s   (출력이 s로 나뉘는 효과)
FC.weight       *= s    (입력이 s로 나뉘는 것을 보상)

→ 수학적으로 동치, 추론 시 오버헤드 없음
```

### 2-5. `smooth_ln_fcs_by_scale` / `smooth_lm_by_scale` (실습 3 — 고정 scale smoothing)

> **역할**: 고정된 scale 값으로 LayerNorm과 FC 사이에 SmoothQuant 적용.

```python
@torch.no_grad()
def smooth_ln_fcs_by_scale(ln, fcs, scale):
    if not isinstance(fcs, list): fcs = [fcs]
    
    # Step 1: LayerNorm weight/bias를 scale로 나눔 → activation 출력 축소
    ln.weight.div_(scale)
    ln.bias.div_(scale)

    # Step 2: 후속 FC weight를 scale로 곱함 → weight 쪽 난이도 흡수
    for fc in fcs:
        fc.weight.mul_(scale)

@torch.no_grad()
def smooth_lm_by_scale(model, scale):
    for name, module in model.named_modules():
        if isinstance(module, OPTDecoderLayer):
            # Attention 부분
            smooth_ln_fcs_by_scale(
                module.self_attn_layer_norm,
                [module.self_attn.q_proj, module.self_attn.k_proj, module.self_attn.v_proj],
                scale
            )
            # FFN 부분
            smooth_ln_fcs_by_scale(module.final_layer_norm, module.fc1, scale)
```

### 2-6. `get_act_scales` — Activation 스케일 수집

> **역할**: 각 Linear layer 입력의 채널별 **최대 절댓값**을 수집. `get_calib_feat`의 "평균" 방식과 달리 여기서는 **최대값**을 사용 (SmoothQuant에서는 최악의 경우를 기준으로 scale 결정).

```python
def get_act_scales(model, tokenizer, dataset_path, num_samples=512, seq_len=512):
    act_scales = {}

    def stat_tensor(name, tensor):
        hidden_dim = tensor.shape[-1]
        tensor = tensor.view(-1, hidden_dim).abs().detach()
        comming_max = torch.max(tensor, dim=0)[0].float().cpu()  # 채널별 최대값

        # 배치 간 누적 최대값 갱신
        if name in act_scales:
            act_scales[name] = torch.max(act_scales[name], comming_max)
        else:
            act_scales[name] = comming_max

    def stat_input_hook(m, x, y, name):
        if isinstance(x, tuple): x = x[0]
        stat_tensor(name, x)

    # 모든 Linear에 hook 등록
    hooks = [m.register_forward_hook(partial(stat_input_hook, name=n))
             for n, m in model.named_modules() if isinstance(m, nn.Linear)]

    for i in range(num_samples):
        input_ids = tokenizer(dataset[i]["text"], ...).input_ids.to(device)
        model(input_ids)

    for h in hooks: h.remove()
    return act_scales  # { layer_name: (hidden_dim,) 채널별 최대 absmax }
```

### 2-7. `smooth_ln_fcs` / `smooth_lm` (실습 4 — Alpha 기반 자동 scale 설정)

> **역할**: activation 최대값과 weight 최대값 모두를 고려하여 최적의 채널별 scale을 자동으로 계산.

**Scale 공식**:
```
s = max(|X|)^α / max(|W|)^(1-α)

α = 0   → s = max(|W|)   (weight 양자화를 쉽게, activation은 어려워짐)
α = 0.5 → s = geometric mean (균형)
α = 1   → s = max(|X|)   (activation 양자화를 쉽게, weight는 어려워짐)
```

```python
@torch.no_grad()
def smooth_ln_fcs(ln, fcs, act_scales, alpha=0.5):
    device, dtype = fcs[0].weight.device, fcs[0].weight.dtype
    act_scales = act_scales.to(device=device, dtype=dtype)

    # 후속 FC들의 입력 채널별 weight 최대값 계산
    weight_scales = torch.cat(
        [fc.weight.abs().max(dim=0, keepdim=True)[0] for fc in fcs], dim=0
    ).max(dim=0)[0].clamp(min=1e-5)

    # s = act_scales^α / weight_scales^(1-α)
    scales = act_scales.pow(alpha) / weight_scales.pow(1 - alpha)
    scales.clamp(min=1e-5).to(device).to(dtype)

    # LayerNorm / FC 파라미터에 반영
    ln.weight.div_(scales)
    ln.bias.div_(scales)
    for fc in fcs:
        fc.weight.mul_(scales.view(1, -1))
```

**α에 따른 양자화 난이도 분배**:

```
                   Activation 양자화 난이도
                   쉬움 ◄──────────────────► 어려움
                    │                        │
                  α=1.0                    α=0.0
                    │                        │
                  어려움 ◄──────────────────► 쉬움
                   Weight 양자화 난이도

              최적 균형점: α ≈ 0.5 (보통)
```

## Part 3 — Rotation-based Quantization (QuaRot / SpinQuant)

---

### 3-1. Rotation 기반 양자화 원리

**문제**: AWQ, SmoothQuant로도 완전히 해결되지 않는 outlier 존재.

**아이디어**: 직교 행렬 R을 삽입하여 activation 분포를 회전시켜 outlier를 균일하게 분산.

```
수식 유도:
y = x · W
  = x · (R·Rᵀ) · W          (RRᵀ = I 삽입)
  = (x·R) · (Rᵀ·W)
  = x' · W'

x' = x·R    → outlier가 분산된 새로운 activation
W' = Rᵀ·W  → 회전된 weight (수학적으로 동치)
```

```
직교 행렬의 특성:
  R · Rᵀ = I       (항등 행렬)
  |v · R| = |v|    (길이 보존)
  방향만 변하고 크기(norm)는 유지
```

---

### 3-2. `get_orthogonal_matrix` — 직교 행렬 생성

```python
def get_orthogonal_matrix(size, mode="random", dtype=torch.float32, device="cpu"):
    if mode == "random":
        A = torch.randn(size, size, dtype=torch.float32, device=device)
        Q, R = torch.linalg.qr(A)          # QR 분해
        Q *= torch.sign(torch.diag(R)).unsqueeze(0)  # 부호 보정
        return Q.to(dtype)
```

**QR 분해로 직교 행렬을 얻는 이유**:
```
임의 행렬 A = Q · R
  Q: 직교 행렬 (Q·Qᵀ = I)
  R: 상삼각 행렬

→ Q를 사용하면 됨
부호 보정: torch.sign(diag(R))로 Q의 각 열 방향 부호를 일정하게 맞춤
```

### 3-3. `fuse_ln_linear` / `fuse_layer_norms_tinyllama` — LayerNorm 융합

> **필요 이유**: Rotation 적용 시 LayerNorm이 중간에 있으면 회전 행렬이 정상적으로 소거되지 않음. 따라서 LayerNorm의 γ(weight), β(bias)를 이후 Linear layer에 흡수시켜 LayerNorm을 항등 연산으로 만들어야 함.

```python
def fuse_ln_linear(layernorm, linear_layers):
    for linear in linear_layers:
        W_ = linear.weight.data.double()

        # W' = W * γ (LayerNorm scale을 Linear weight에 흡수)
        linear.weight.data = (W_ * layernorm.weight.double()).to(linear.weight.dtype)

        # b' = b + W * β (LayerNorm bias를 Linear bias에 흡수)
        if layernorm.bias is not None:
            if linear.bias is None:
                linear.bias = nn.Parameter(torch.zeros(...))
            linear.bias.data = linear.bias.data.double() + (W_ @ layernorm.bias.double())
            linear.bias.data = linear.bias.data.to(linear.weight.dtype)
```

```
융합 전:
  x → [LayerNorm(γ, β)] → [Linear(W, b)] → y

융합 후:
  LayerNorm(γ, β) = Linear(W·γ, b + W·β) + LayerNorm(1, 0)
  
  ∴  x → [LayerNorm(1, 0)] → [Linear(W', b')] → y
                 ↑
          항등 연산으로 무력화 (weight=1로 초기화)
```

#### `fuse_layer_norms_tinyllama` — TinyLlama 전체 구조에 적용

```python
def fuse_layer_norms_tinyllama(model):
    # (1) Embedding 중심화: 평균 제거 (embed의 bias 제거 효과)
    for W in [model.model.embed_tokens]:
        W.weight.data = W_ - W_.mean(dim=-1, keepdim=True)

    for layer in model.model.layers:
        # (2) Attention 입력 LayerNorm → Q, K, V에 흡수
        fuse_ln_linear(layer.input_layernorm,
                       [layer.self_attn.q_proj, layer.self_attn.k_proj, layer.self_attn.v_proj])

        # (3) FFN 입력 LayerNorm → gate_proj, up_proj에 흡수
        fuse_ln_linear(layer.post_attention_layernorm,
                       [layer.mlp.gate_proj, layer.mlp.up_proj])

        # (4) LayerNorm weight를 1로 초기화 (사실상 항등 연산)
        layer.input_layernorm.weight.data = torch.ones_like(...)
        layer.post_attention_layernorm.weight.data = torch.ones_like(...)

    # (5) 최종 LayerNorm → LM Head에 흡수
    fuse_ln_linear(model.model.norm, [model.lm_head])
    model.model.norm.weight.data = torch.ones_like(...)
```

**TinyLlama 구조와 융합 위치**:

```

    │  ← (1) 평균 중심화
    ▼
LlamaDecoderLayer × 22
    │
    ├─ [input_layernorm]  ← (2) Q,K,V에 흡수 → 항등화
    ├─ Self-Attention
    │    ├─ q_proj ← γ, β 흡수
    │    ├─ k_proj ← γ, β 흡수
    │    ├─ v_proj ← γ, β 흡수
    │    └─ o_proj
    │
    ├─ [post_attn_layernorm]  ← (3) gate/up에 흡수 → 항등화
    └─ MLP
         ├─ gate_proj ← γ, β 흡수
         ├─ up_proj   ← γ, β 흡수
         └─ down_proj
    │
    ▼
[model.norm]  ← (5) lm_head에 흡수 → 항등화
    │
lm_head
```

### 3-4. `rotate_model_weight` — Weight Space Rotation (실습 5)

> **역할**: 모든 Embedding, Linear layer에 직교 행렬 R1을 적용하여 Weight Space Rotation 수행.

```python
def rotate_model_weight(model, R1):
    for n, m in model.named_modules():
        if isinstance(m, nn.Embedding):
            # Embedding: (num_tokens, hidden_dim)
            # x' = x·R1 이므로, Embedding도 동일하게 회전
            m.weight.data = m.weight.data @ R1

        if isinstance(m, nn.Linear):
            # o_proj, down_proj: 출력 프로젝션 (hidden_dim 방향이 입력)
            # y = (x·R1) · (R1ᵀ·W) → 입력이 회전되었으므로 W에 R1ᵀ를 곱
            if "o_proj" in n or "down_proj" in n:
                m.weight.data = R1.T @ m.weight.data

            # q/k/v_proj, gate/up_proj: 입력 프로젝션
            # 입력이 회전된 x' = x·R1에서 연산하므로 W에 R1을 곱
            else:
                m.weight.data = m.weight.data @ R1
```

**Rotation 적용 원리 (Layer별 분석)**:

```
원래:  y = x · W
회전 후: y = (x · R1) · (W · R1)   ← 입력/출력 모두 회전 공간

─────────────────────────────────────────────────
Layer 유형별 처리:

[입력 프로젝션] q/k/v_proj, gate_proj, up_proj
  입력: x' = x · R1  (회전된 activation)
  수식: y = x' · W = (x·R1) · W
  조정: W_new = W · R1  (Weight에 R1 곱)
  결과: y = x · (W · R1) = x · W_new  ✓

[출력 프로젝션] o_proj, down_proj
  입력: x' (이미 회전된 공간에 있음)
  수식: y' = x' · W → y = y' · R1ᵀ  (출력 회전 해제)
  조정: W_new = R1ᵀ · W
  결과: y = x' · W_new = x' · R1ᵀ · W  ✓

[Embedding]
  W_new = W · R1   (입력 공간 회전)
─────────────────────────────────────────────────
```

**Rotation의 Outlier 완화 효과**:

```
회전 전:
  채널   │ 0  1  2  3 ... 50          ... 99
  값     │ 0.1 0.2 0.1 0.1 ... [30.0] ... 0.1
                                ↑ outlier!

회전 후 (직교 행렬 적용):
  채널   │ 0  1  2  3  4  5 ... 99
  값     │ 0.8 0.9 0.7 0.8 1.1 0.9 ... 0.8
                (outlier가 전체 채널에 분산됨)
```

## 전체 알고리즘 비교 정리

| 항목 | **AWQ** | **SmoothQuant** | **Rotation-based** |
|------|---------|-----------------|-------------------|
| 양자화 대상 | Weight만 (W4A16) | Weight + Activation (W8A8) | Weight + Activation (W4~8A8) |
| 핵심 아이디어 | 중요 채널 scale-up | Quantization 난이도를 W로 이전 | Outlier를 분산시켜 제거 |
| Calibration 통계 | Activation 평균값 | Activation 최대값 | 불필요 (Random R) |
| Scale 적용 위치 | LayerNorm, FC 파라미터 | LayerNorm, FC 파라미터 | 모든 Embedding, Linear |
| 장점 | 낮은 bit (3~4bit) 가능 | INT8 GEMM 가속 가능 | Outlier 근본적 제거 |
| 단점 | Dequant 후 FP16 연산 | Activation 비트 확보 어려움 | LayerNorm 융합 필요 |
| 대표 논문 | AWQ (MIT Han Lab) | SmoothQuant (MIT Han Lab) | QuaRot, SpinQuant |
